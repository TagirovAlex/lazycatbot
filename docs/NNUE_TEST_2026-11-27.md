# Тест встроенного NNUE: классика против NNUE

- Дата: 2026-11-27
- Движок: `chessbot.exe` (PGO `B437719A...7235DF`, все фиксы подтверждённых багов)
- Формат: 40 зеркальных партий (20 пар Opening), 100 мс/ход
- Потоки: 1 на движок, Hash 64, Move Overhead 0
- A: `UseNNUE=false` (классическая оценка)
- B: `UseNNUE=true`, `NNUEWeight=25`, `NNUEClip=80`

## Результат

```text
A W/D/L: +20 =13 -7
score: 26.5/40 = 0.662
Elo difference (A-B): +117
95% pair-level CI: +33 .. +218
engine errors: 0; restarts: 0; aborts: 0
```

Классическая оценка уверенно выиграла матч. Встроенная residual-сеть
(768x64x1, обучена на ~27.5 тыс. позиций) при рекомендованном весе 25
не просто не даёт прибавки, а ухудшает игру на этом контроле.

## Проверка, что NNUE действительно включался

```text
UseNNUE=false:
info string classical(stm) 10 neural 0  total 10 ... enabled 0 weight 25 clip 80

UseNNUE=true:
info string classical(stm) 10 neural 11 total 12 ... enabled 1 weight 25 clip 80
```

## Вывод

Оставляем `UseNNUE: false` в `lichess-bot/config.yml`. Для реального
усиления нужна другая сеть и/или обучение на большем объёме данных,
а не включение текущих весов.
