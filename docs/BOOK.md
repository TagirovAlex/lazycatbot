# Книга дебютов

## Что есть

`data/books/lichess_masters.bin` — Polyglot-книга, собранная из публичного
Lichess Masters Explorer (не из сырых PGN).

| Параметр | Значение |
|---|---:|
| Формат | Polyglot, 16 байт/запись |
| Позиций | 921 |
| Записей | 1 647 |
| Глубина | 9 полуходов |
| Ветвление | 4 хода в корне, 2 дальше |
| Мин. партий на ход | 20 |
| Размер | 26 352 байта |
| SHA-256 | `dc98179e6763c01d9d8bfb6f90cd1b81e774c4a1007a7b5d361b5dc2f62b66fe` |
| Проверка | 0 нелегальных ходов/ключей |

Стартовые кандидаты и веса:

```text
e2e4 13681
d2d4 10705
g1f3 3032
c2c4 2063
```

Это не «книга на 20 ходов», а компактный мастерский дебютный репертуар:
первые 9 полуходов, без мусорных линий. Для блица этого достаточно, чтобы
не тратить время на дебют и не получать ранние проигрыши.

## Генерация

```powershell
python tools\make_lichess_book.py `
  --depth 9 --max-moves 2 --root-moves 4 --min-games 20
```

Скрипт:

- идёт BFS по позициям от startpos;
- запрашивает `https://explorer.lichess.ovh/masters?fen=...`;
- оставляет только ходы с достаточным числом партий;
- пишет Polyglot-записи, сортирует по ключу;
- проверяет каждый ход через `python-chess` и сохраняет манифест;
- кэширует ответы в `data/books/lichess_masters.cache.json` (можно
  прерывать и продолжать).

## Статус интеграции

Книга уже читается старым book-бинарником эксперимента:

```text
info string book loaded data/books/lichess_masters.bin entries 1647
info string book move d2d4 weight 10705 candidates 4 key 463b96181691fc9c
```

В основной `src/` поддержка книги пока **не включена**. Агент
`experiments/book_mt` портирует Polyglot-интеграцию на текущую
MT/Syzygy-версию. Включать `OwnBook=true` по умолчанию можно только после
A/B: книга не должна ухудшать результат и не должна мешать Syzygy.

## Лицензия/источник

Источник ходов — публичный Lichess Masters Explorer
(<https://explorer.lichess.ovh/masters>). Сама книга сгенерирована проектом;
при распространении укажите Lichess как источник статистики. Polyglot —
стандартный формат, реализация чтения в `experiments/book/src/book.cpp`.
