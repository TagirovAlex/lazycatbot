# Мини-дашборд партий

Локальная страница для наблюдения за LazyCatBot:

```powershell
python tools\bot_dashboard.py --port 8765
```

Открыть: <http://127.0.0.1:8765/>

## Что показывает

- текущие партии: локальная доска (SVG из FEN), соперник, цвет, контроль, часы,
  чей ход, список ходов SAN;
- навигация по всей партии: `⏮` в начало, `◀` назад, `▶` вперёд, `⏭` в конец/live,
  плюс клик по любому ходу;
- если партий нет — последнюю завершённую;
- рейтинги bullet/blitz/rapid/classical и статус онлайн;
- последние 12 партий: результат, рейтинг-диф, контроль, статус.

Обновление данных — каждые 5 секунд. Доска рисуется на сервере через
`python-chess` SVG, без iframe Lichess: ходы и позиция видны даже если
встраивание Lichess заблокировано браузером.

## Безопасность

- Сервер слушает только `127.0.0.1` по умолчанию.
- Токен читается на сервере из `C:\LichessBot\lichess-bot\config.yml` и **не**
  передаётся в HTML/JS.
- В браузере видны только публичные данные партий и рейтинги.
- Не ставьте `--host 0.0.0.0` без пароля/файрвола: дашборд не имеет авторизации.
- После перевыпуска токена перезапустите дашборд.

## Опции

```text
--host 127.0.0.1   адрес (по умолчанию только локально)
--port 8765        порт
--user LazyCatBot  имя бота
--config PATH      путь к config.yml с токеном
```

## Зависимости

`requests`, `PyYAML`, `python-chess` — уже стоят вместе с `lichess-bot`.

## Ограничения

- Нужен доступ к `lichess.org` (API и PGN export).
- `/api/account/playing` требует `bot:play`; без токена текущие партии не
  показываются.
- `/api/games/user/...` для бот-аккаунта здесь работает только с токеном,
  поэтому дашборд использует авторизованный запрос.
- При 429 Lichess дашборд показывает кэш и предупреждение, но не падает.
